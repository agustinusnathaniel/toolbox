New developer tools for text and types, with a clearer diff view and smoother handling of large inputs.

### What's New

- **Case Converter** — switch text between camelCase, PascalCase, snake_case, kebab-case, and more with one click, and share your results with a link.

- **JSON to TypeScript** — paste JSON and generate ready-to-use TypeScript interfaces, with your settings preserved in a shareable link.

### Improvements

- **Text Diff split view** — compare two texts side-by-side with sharper, word-level highlighting so changes are easier to spot.

- **More shareable tools** — password, case converter, and JSON-to-TypeScript tools now keep their settings in a link, making it easier to share or return to your work.

### Bug Fixes

- **Stable command menu** — the global search menu no longer crashes.

- **Freeze-free CSV conversion** — converting large CSV files now runs in the background, so the tab stays responsive.
