The first public release of Toolbox — a unified collection of browser-based utilities. Everything runs locally in your browser; no data is sent to any server.

### Tools

- **WhatsApp Link Helper** — generate clickable WhatsApp links with pre-filled messages, phone numbers, and country codes
- **QR Code Generator** — create QR codes for URLs or contacts with customizable colors and download as an image
- **User Agent Check** — see what information your browser sends about your device, operating system, and browser
- **JS Perf Comparator** — run two JavaScript snippets side-by-side and compare their execution time with reliable, averaged results
- **Zippy Image** — compress images right in your browser with adjustable quality settings
- **Add to Calendar** — generate Google Calendar event links with title, location, description, and time
