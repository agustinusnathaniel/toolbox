A round of quality-of-life improvements that make navigating and using the tools smoother.

### New Features

- **Keyboard shortcuts** — press 1 through 7 to jump directly to any tool from the home page
- **Shareable URLs** — WhatsApp Link Helper and Add to Calendar now sync their state to the URL. Share a link and the recipient sees the same configuration
- **Persistent state** — your inputs are saved between visits, so your work is still there when you come back
- **Dark mode QR codes** — the QR Code Generator now offers a dark mode preset for better contrast on light backgrounds
- **Compression stats** — Zippy Image shows before and after file sizes so you can see how much you saved
