Six new tools to make your day easier — all private, all in your browser.

### What's New

- **JWT Decoder** — paste a token to instantly see who issued it, when it expires, and what permissions it grants. Verify signatures too
- **Hash Generator** — create a unique fingerprint of any file or piece of text to verify it hasn't been changed
- **Password Generator** — create strong, random passwords with a strength meter and control over what characters to include
- **Base64 Encoder/Decoder** — convert text to Base64 and back, handy for URLs and configs
- **JSON Formatter** — clean up messy data with one click — pretty-print, validate, or compress it
- **Color Converter** — pick a color or type a value and see it in any format: HEX, RGB, HSL, or OKLCH

### Improvements

- **Zippy Image** — loads large images more efficiently with less memory
- **QR Code Generator** — trimmed dead code for a leaner, faster tool
- **Security updates** — updated dependencies and tightened security headers across the app

### Bug Fixes

- **Security headers** — consistent protection across all versions of the site
- **Smoother transitions** — page transitions no longer break on older browsers
