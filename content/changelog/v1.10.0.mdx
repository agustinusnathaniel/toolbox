Nine new tools for everyday tasks, a refreshed interface, and more shareable links.

### What's New

- **URL Encoder & Decoder**: encode or decode full URLs and URI components safely.

- **Cron Expression Parser**: turn cron expressions into plain English and preview the next run times.

- **Markdown Preview**: write Markdown and watch it render live as you type.

- **HTML Entity Codec**: encode or decode HTML entities like `&`, `<`, and `>` without leaving your browser.

- **YAML Converter**: convert between JSON and YAML in either direction.

- **SQL Formatter**: clean up and beautify SQL for MySQL, PostgreSQL, SQLite, BigQuery, Transact-SQL, and generic SQL.

- **Number Base Converter**: convert numbers between binary, octal, decimal, and hexadecimal, with common prefixes recognized.

- **Unit Converter**: convert length, weight, temperature, volume, and data storage units.

- **Lorem Ipsum Generator**: create placeholder text with control over paragraphs, sentences, and words.

### Improvements

- **Shareable links for every new tool**: input and settings stay in the link, and the JS Performance Comparator can now save a full benchmark setup.

- **Hash verification**: paste an expected hash to see instantly whether your text or file matches, and share the expected hash in a link.

- **Faster on large inputs**: the JSON Formatter and JSON to TypeScript tools now run in the background, so the page stays responsive.

- **Refreshed interface**: the sidebar groups tools into collapsible categories, and controls across the app have a cleaner, more consistent look.

- **Even stronger passwords**: the Password Generator now picks characters with uniform randomness.

### Bug Fixes

- **Accurate JWT verification**: a valid signature is no longer reported as invalid just because the token is expired or not yet active.

- **Reliable pinned tools**: invalid saved data no longer breaks your pinned tools list.
